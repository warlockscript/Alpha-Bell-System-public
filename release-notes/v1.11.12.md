## Changed

- **Audio is added in one place: Media Player → + Add Files.** Choosing audio for a task or a Schedule Center entry now opens a list of the files already in the bell system's audio folder — nothing outside it. A bell can no longer point at a file on a USB stick or in Downloads that disappears later. To use a new sound, add it with **+ Add Files** first.

## New

- **It tells you when a file is already there.** If the file you add is identical to one already in the audio folder — even under a different name — you are offered the existing file instead of storing a second copy.
- **Remove tracks from the Media Player.** The new **✕ Remove** button moves one or several selected tracks to the Recycle Bin. It refuses any file a schedule, preset, task, zone tone or paging chime still uses, and says where it is used.

## Fixed

- **Damaged audio is caught when you add it.** A WAV or OGG file that was cut short — an interrupted copy, a failing USB stick — used to be accepted and then fail silently when its bell was due. **+ Add Files** now rejects it and says how much of it is missing.
- **The Media Player scrubber resets when Quick Play stops.** Stopping or closing Quick Play mid-track no longer leaves the progress bar frozen where the audio was cut.
